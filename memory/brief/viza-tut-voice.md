# Голос — Виза тут

Коротко, по-русски, спокойно. Читатель взрослый.

Говорим, что делаем мы: анкета, проверка комплекта, запись. Не обещаем решение консульства.

Без канцелярита и без рекламного крика. Без названий чужих агентств. Без слова «пакет».

Заголовки страниц услуг остаются крупными. В статье заголовок отвечает на вопрос человека, не на название фирмы.
